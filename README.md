## Deploy to Vercel

Import this repository into Vercel. It is detected automatically as a Next.js project.

- Build command: `npm run build`
- Output directory: leave the default
- Environment variables: none required

The download counts are fetched in the browser from the public GitHub Releases API on each page load.
